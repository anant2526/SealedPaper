# Sample question files

For the demo, give each paper setter one of these files and use **Import a file** on the paper page.
They fit this blueprint:

| Topic | Difficulty | Questions | Marks each |
| --- | --- | --- | --- |
| Arrays | Easy | 3 | 2 |
| Trees | Medium | 3 | 4 |
| Graphs | Hard | 2 | 6 |

Together the two files put 17 questions in the pool for 8 places, so the draw at release has a real choice.
Format: `topic`, `difficulty` (`easy` / `medium` / `hard`), `text`, `options` (2 to 6), `answer` (index of the correct option, from 0).
